Classes are the core organizing unit in EcoLearn. Each class has its own roster, assignment queue, gradebook, and settings, so you can run multiple sections of the same course — or completely different courses — without any overlap. Once a class is created, students join using a simple join code, and you can add or remove them at any time throughout the year.

## Creating a New Class

<Steps>
  <Step title="Open the New Class form">
    From your **Educator Dashboard**, navigate to **Classes** in the left sidebar and click **New Class**.
  </Step>
  <Step title="Enter class details">
    Provide a **class name** (e.g., "Period 3 – Environmental Science"), the **subject** (e.g., Ecology, Biology), and the **grade level** or age range of your students.
  </Step>
  <Step title="Choose a color and icon">
    Select a **class color** and **icon** to visually distinguish this class from others on your dashboard. These are purely cosmetic but make navigation faster when you manage several sections.
  </Step>
  <Step title="Set the academic year">
    Choose the **academic year** (e.g., 2024–2025). This groups your classes by year so past classes remain accessible without cluttering your active view.
  </Step>
  <Step title="Create the class">
    Click **Create Class**. EcoLearn immediately generates a **Class Join Code** — a unique 6-character alphanumeric code (for example, `XK7T2A`) that students use to enroll themselves.
  </Step>
</Steps>

## Sharing the Join Code

Your Class Join Code appears at the top of the **Class Overview** page. You can also find it anytime under **Class Settings → Join Code**.

To enroll, students go to **Account Setup → Join a Class → Enter Code**, type in the 6-character code, and click **Join**. Their name appears in your roster within seconds.

If you suspect the code has been shared with someone outside your class, you can invalidate it immediately:

1. Go to **Class Settings → Join Code**.
2. Click **Generate New Code**.
3. Confirm the action. The old code stops working instantly, and a fresh code is displayed.

Distribute the new code to students who still need to join through your usual channels (LMS announcement, email, or in-class display).

## Managing Your Roster

You have three ways to populate your class roster:

- **Add a student manually** — click **Roster → Add Student**, enter the student's email address, and click **Send Invite**. The student receives an email prompting them to create an account or log in and join your class.
- **Import via CSV** — click **Roster → Import CSV**. Download the provided template, fill in student names and email addresses, and re-upload the file. EcoLearn validates each row and flags any errors before importing.
- **Remove a student** — locate the student in your roster, click the **⋯** menu next to their name, and select **Remove from Class**. Their historical submissions remain in your gradebook for record-keeping but they lose access to class assignments.

## Class Settings

Open **Class Settings** from the gear icon on any Class Overview page to configure the following options:

- **Grading visibility** — choose whether students can see their scores and feedback as soon as work is graded, or only when you manually release grades.
- **Class leaderboard** — enable or disable the optional engagement leaderboard that ranks students by points earned. You can make it visible to the whole class or restrict it to you only.
- **Assignment due-date reminders** — set automatic email and in-app reminders to go out 24 hours and 1 hour before each assignment deadline, keeping students on track without extra effort from you.
